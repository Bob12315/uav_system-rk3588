任务控制

          

            
            
            
            
            
            
            
            
          

          
仅配置任务步骤，不发送飞控命令。

          
System SEND=OFF

          

            配置只加载步骤，不会发送命令。启动只创建任务运行器。
            推进会执行下一轮 Action；当 System SEND=ON 时，推进可能下发 local_position/body_velocity/set_servo 命令。
            跳过当前阶段会停止当前 Action、清理连续控制和 LOCAL_POSITION，并尝试保持当前位置，然后启动下一阶段；不会清空黑板。
            切换模板前请先停止或重置。

手动步长移动

        

          
          
        

        

          

            
            
            
            
            
            
            
            
            
          

          

            
            
            
            
          

        

        
机体系单步移动；后端读取当前 LOCAL_NED 和 yaw，换算为 LOCAL_NED 绝对位置目标，并保持当前 yaw。执行前会停止当前 Action 并清理连续控制。

      


      

        
Manual Command

        

          手动命令会直接进入后端命令解析；飞控实发仍受 SEND / 模式 / 解锁状态影响。危险命令请确认后再发送。
        

        

          
          
          
        

        
支持与主命令行相同的命令；复杂命令可在 Config / Logs 页使用完整命令行。

        

          常用命令：
          mode GUIDED
          arm
          land
          mode RTL
          controller all off
