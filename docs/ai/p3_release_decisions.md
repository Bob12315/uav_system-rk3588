# P3 维护者发布决策记录

本文件是公开发布前的内部决策记录，**不是**可直接随发布包使用的法律或社区文件。
在所有项目由授权维护者填写并可核验前，仓库保持“禁止公开发布”。

| 编号 | 必须由维护者确认的事实 | 已确认？ | 证据位置 |
| --- | --- | --- |
| D-09 | 版权主体、年份，以及现有主要贡献者/权利人同意 Apache-2.0 | 否 | — |
| D-10 | 采用 DCO 或 CLA，并确定执行方式 | 否 | — |
| D-11 | 私密安全报告渠道与 Code of Conduct 执行联系人 | 否 | — |
| D-12 | 模型、数据集、图片、视频、地图/地形、字体和 Logo 的来源、许可与再分发权 | 否 | — |

确认后，维护者应在同一评审中新增正式 `LICENSE`、`NOTICE`、`CONTRIBUTING.md`、
`SECURITY.md`、`CODE_OF_CONDUCT.md`、`THIRD_PARTY_NOTICES.md`、`ASSETS_LICENSES.md` 和
`MODEL_CARD.md`。不得将本表中的“否”或空证据替换成虚构联系人、组织名称或许可证。
