# 11：第一次实飞

## 本章目标

在有经验的飞手、观察员和安全场地下，从人工控制、只读记录逐步过渡到低速、无载荷、
单项 Action 验证。第一次实飞不运行完整比赛任务。

> 实飞具有人员伤害和财产损失风险。必须遵守当地法规、场地规则和队伍安全流程。本章
> 不能替代飞控厂商、ArduPilot 或机架的安全手册。

## 必须满足的前置条件

- 机架、动力、飞控和遥控系统已由有经验人员完成常规首飞；
- 完成飞控全部必要校准和 failsafe 设置；
- 遥控器/地面站可以接管，飞手清楚模式切换和急停流程；
- 无桨台架测试和 SITL 全部完成；
- 无正式载荷，投放机构断开或使用安全模拟件；
- 电池、天气、空域、人员隔离和消防准备符合要求；
- 当前 commit、配置和模型已记录；
- SEND 在起飞前保持 OFF。

## 推荐分级

### A. 人工飞行，只记录

关闭系统 SEND，由飞手人工起飞、悬停、平移、转向和降落。RK3588 只记录 telemetry、
相机、YOLO 和 blackbox。检查是否发生电源掉压、计算板重启、网络丢失或图像延迟。

### B. 人工飞行，验证 FIELD 方向

在安全高度和低速下由飞手运动，比较 Web 地图、GLOBAL/LOCAL 状态和真实方向。发现坐标
不一致立即停止自动化测试并重新建立 Field Reference。

### C. 单个低风险 Action

在 SITL 已验证的参数基础上，先验证可立即停止的低速航点/模式。启用 SEND 前进行口头
确认：飞手、观察员、操作员、测试目标、停止条件和接管方式。

### D. 起飞/降落分项

单独验证自动起飞和降落，不串联识别、投放或完整 Mission。每项完成后下载日志并复盘。

### E. 无载荷视觉分项

验证扫描、目标锁定、对准下降和丢目标停止。载荷仍不安装，投放输出保持断开。

## 每次自动动作前口令

```text
场地净空？
飞手已接管待命？
测试动作和停止条件明确？
Field Reference 正确？
速度、高度和目标已复核？
SEND 和 send_actions 状态明确？
日志正在记录？
```

## 立即终止条件

- 姿态、方向或高度异常；
- 飞机运动与命令方向不一致；
- telemetry stale、GPS/EKF 异常或网络反复断开；
- 相机/YOLO 丢失后仍持续运动；
- RK3588 或飞控重启；
- 人员进入安全区；
- 飞手、观察员或操作员任一人喊停。

终止后优先由飞手/地面站接管。停止 app 只能作为辅助路径。

## 完成检查表

- [ ] 人工飞行期间 RK3588 供电、散热和日志稳定。
- [ ] FIELD 与真实方向一致。
- [ ] 单个 Action 在保守参数下可执行并可停止。
- [ ] 丢目标、断链和 Action Stop 不保留旧运动。
- [ ] 起飞、降落、视觉分项均有独立日志和复盘记录。
- [ ] 尚未因为“分项成功”直接宣告完整比赛任务可用。
