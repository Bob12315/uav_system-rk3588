# 03：机械组装

## 本章目标

在不通电、不装桨的状态下，完成机架、飞控、RK3588、下视相机和投放机构的机械安装。

预计时间：半天到一天。需要准备：机架说明书、紧固件、螺纹胶、扎带、减震材料、尺和秤。

## 开始前

- 拆下全部螺旋桨；
- 电池不接入整机；
- 给所有线缆和部件贴标签；
- 拍摄机架上、下、前、后四个方向的基准照片；
- 确认机头方向，并在机架上做永久标记。

## 推荐组装顺序

### 1. 机架和动力系统

按机架、电机和电调厂商说明安装。检查所有机臂长度和电机座方向一致。此时只完成机械
固定，不连接动力电池，也不安装螺旋桨。

### 2. 飞控

飞控应靠近机体中心，方向箭头与配置一致，并避免硬连接传递电机振动。记录：

- 飞控型号和硬件版本；
- 安装方向；
- 使用的减震方案；
- GPS、MAVLink 和 SERVO 接口位置。

如果飞控无法按默认方向安装，应在 ArduPilot 中正确设置板载方向，而不是在软件坐标
代码中“补偿”。

### 3. GPS/罗盘

尽量远离动力线、电调、大电流 DC-DC 和磁性材料。GPS 箭头方向必须与飞控配置一致。
安装后记录杆高、方向和线缆走向。

### 4. RK3588 和散热

选择有空气流动、便于插拔存储和网络线、不会被投放机构撞击的位置。必须：

- 安装散热器，使用风扇时固定风扇线；
- 避免板卡底部接触碳纤维、金属螺丝或导电物；
- 给 USB、网线和电源线预留应力释放；
- 保证更换存储或进入维护接口时不必拆完整机。

### 5. 下视相机

相机光轴应尽可能垂直向下，画面方向与项目坐标约定一致。先做机械基准，不要通过软件
镜像掩盖装反。记录相机相对机体中心和投放点的前、右偏移。

详细要求见 [相机安装](../hardware/camera_setup.md)。

### 6. 投放机构

分别标记 payload 1 和 payload 2。检查机构在保持和释放位置都不会碰撞螺旋桨、机臂、
相机或地面。舵机摇臂不应在机械极限处持续堵转。

### 7. 初步重心

按正式比赛状态放置电池、RK3588、相机和两个等重模拟载荷。重心应满足机架/飞控要求。
分别模拟释放第一个和第二个载荷，记录重心变化。重心不合格时调整布局，不要依靠控制
参数掩盖明显的机械不平衡。

## 走线原则

- 大电流动力线与 GPS/罗盘、信号线尽量分离；
- 所有插头有防松和应力释放；
- 线缆不经过螺旋桨扫掠区域；
- 相机、网线和 USB 线不会因云台/减震运动被拉扯；
- 给电池、RK3588 和飞控保留独立断电能力；
- 标签能够在装机后看见。

## 正确结果

整机在不通电状态下结构牢固，飞控方向、相机方向、机头方向和两个投放机构均有明确
标记；移动机体时没有松动、干涉或线缆拉扯。

## 完成检查表

- [ ] 飞控方向和机头方向已拍照记录。
- [ ] RK3588 有散热、绝缘和线缆应力释放。
- [ ] 下视相机固定牢靠且无遮挡。
- [ ] 两个投放机构已编号且无机械干涉。
- [ ] 满载和单次释放后的重心均已检查。
- [ ] 所有紧固件和线缆已复核。
