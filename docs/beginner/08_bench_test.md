# 08：无桨台架测试

## 本章目标

在整机拆桨、固定、无正式载荷的条件下，验证传感器方向、状态链路、相机坐标和投放机构。
任何会产生电机危险输出的测试必须由熟悉 ArduPilot 的人员负责。

预计时间：1～3 小时。需要准备：牢固台架、万用表、模拟载荷、遥控器/地面站和观察员。

## 安全条件

- 全部螺旋桨拆下并带离工作台；
- 投放机构只使用无危险、低质量模拟件；
- 遥控器/地面站可随时接管；
- 系统 SEND 默认关闭；
- 每次只验证一个子系统；
- 不在人员、玻璃或易损设备上方测试释放。

## 1. 姿态和方向

打开 Web UI 或地面站，手动小角度抬起机头、右侧和机尾，检查 roll/pitch/yaw 变化符合
飞控安装方向。发现方向错误应修正飞控配置或机械安装，不修改比赛坐标代码补偿。

## 2. GPS、高度和 LOCAL_NED

在合适环境确认 GPS fix、卫星数和位置稳定。记录起飞点附近 LOCAL_NED 初值和高度来源。
不要把 GPS Home、EKF Origin 和比赛 FIELD 原点当成同一个概念。

## 3. 相机方向和画面坐标

在相机画面中心放置标志，然后分别移动到画面右侧和下侧，确认：

- `pixel_x/ex_norm` 向右为正；
- `pixel_y/ey_norm` 向下为正；
- 没有输入层镜像；
- 相机实际安装方向与文档一致。

详细记录见 [相机安装](../hardware/camera_setup.md)。

## 4. YOLO 检测

使用比赛目标样本检查类别、置信度、跟踪 ID 和丢失状态。确认移走目标后状态能够变为
lost/invalid，不持续保留旧目标。

## 5. MAVLink 只读状态

保持 SEND=OFF，观察 heartbeat、armed、mode、GPS、姿态、速度和 stale 状态。断开链路后
应看到 connected/control_allowed 变化，恢复连接时不得自动恢复旧动作。

## 6. 投放机构空载测试

这是台架测试中风险最高的一步。先阅读 [投放机构](../hardware/payload_release.md)。

正式软件链路只允许：

```text
payload_release → set_servo → MAV_CMD_DO_SET_SERVO
```

先由硬件/飞控负责人使用安全方法确认具体 SERVO 输出和 PWM，不得根据模板直接假定。
检查单路时断开另一舵机，确认保持、释放、恢复位置和机械电流。最后再用无危险模拟载荷
验证两路不会串扰。

## 7. 故障注入

保持无桨无载荷，验证：

- 遮挡或断开相机后目标失效；
- 停止 yolo 后 app 不沿用旧感知；
- 断开 telemetry 后状态 stale/control disallowed；
- 停止或重置 Action 后旧连续命令被清理。

涉及实发 stop/zero 的项目必须先在 SITL 验证；新手不要在台架临时开启完整任务实发。

## 完成检查表

- [ ] 姿态方向和飞控安装方向一致。
- [ ] GPS、高度、LOCAL_NED 状态已记录。
- [ ] 相机没有意外镜像，画面轴方向已确认。
- [ ] YOLO 丢目标后不会保留有效目标。
- [ ] telemetry 断线和恢复状态符合预期。
- [ ] 两路 SERVO 输出和 PWM 已由人工空载验证并记录。
- [ ] 正式载荷和螺旋桨仍未安装。
