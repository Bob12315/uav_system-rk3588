# 02：准备硬件和填写 BOM

## 本章目标

在购买、接线或写配置前，确认整机所需硬件、准确型号、接口和供电要求。

预计时间：1～3 小时。需要准备：现有硬件照片、商品页面、说明书和万用表。

## 重要原则

下表中的“待确认”必须由装机者填写。仓库当前只能证明软件运行在 Linux ARM64 RK3588、
使用 ArduPilot/MAVLink、下视相机和两路投放输出，不能证明任意具体硬件都兼容。

## 采购前必须核对

1. RK3588 板卡确实运行 aarch64 Linux，并能使用匹配的 RKNNLite/NPU runtime；
2. 下视相机在该系统上有稳定的视频设备或流地址；
3. 飞控支持所选 ArduPilot 固件和 MAVLink 连接方式；
4. RK3588、舵机和飞控供电电压均已从各自说明书确认；
5. DC-DC 连续电流和峰值电流有余量；
6. 飞控有足够的独立 SERVO 输出，且不会与电机/其他设备冲突；
7. 机架载重、空间、散热和重心能够容纳所有部件；
8. 准备备用桨、线材、连接器、保险、扎带和紧固件。

## 不要这样做

- 不要根据颜色猜电源极性或串口定义；
- 不要把飞控 5V 输出默认当作 RK3588 主电源；
- 不要把 SERVO 输出编号和遥控器 RC 通道当成同一个概念；
- 不要购买“理论兼容”替代件后直接进入实飞；
- 不要让 AI 根据模糊照片猜电压和引脚。
