# 03：无人机组装

本章按“机械安装 → 接线记录 → 分阶段供电 → 无桨台架检查”的顺序完成整机组装。

预计时间：1～2 天。需要准备：[配置清单](02_hardware_bom.md) 中的全部硬件、厂商说明书、
万用表、限流或保险方案、装机工具和一名复核人员。

> **全章保持：** 电池断开、螺旋桨拆除、正式载荷移除。任何电压、极性或引脚不确定时
> 立即停止，查阅具体硬件说明书。不要根据线色、照片或 AI 猜测。

## 一、机械安装

### 1. 机架和动力系统

按机架、电机和电调厂商说明安装。确认机头方向并做永久标记，检查机臂长度、电机座方向
和紧固件。此时只做机械固定，不连接动力电池，也不安装螺旋桨。

### 2. 飞控

飞控应靠近机体中心，方向箭头与配置一致，并使用合适的减震方案。记录飞控型号、硬件
版本、安装方向、GPS/MAVLink/SERVO 接口。若不能按默认方向安装，应在 ArduPilot 中
设置板载方向，不能修改比赛坐标代码来补偿。

### 3. GPS 和罗盘

尽量远离动力线、电调、大电流 DC-DC 和磁性材料。GPS 箭头方向必须与飞控配置一致，
安装后记录杆高、方向和线缆走向。

### 4. RK3588 和散热

- 安装散热器，风扇线固定并有应力释放；
- 板卡底部不得接触碳纤维、金属螺丝或其他导电物；
- USB、网线、电源和存储接口便于维护；
- 安装位置不能被投放机构撞击；
- 计算板、飞控和电池尽量具备独立断电能力。

### 5. 下视相机

相机光轴应尽可能垂直向下，原始检测输入不镜像。记录相机相对机体中心和两个投放点的
前、右偏移。先修正机械方向，不要用软件镜像掩盖装反。

| 项目 | 实际值 |
| --- | --- |
| 相机型号/镜头 | 待确认 |
| 接口 | 待确认 |
| 安装方式 | 固定/云台待确认 |
| 光轴方向 | 下视，偏差待测 |
| 相对机体中心：前 | 待确认 m |
| 相对机体中心：右 | 待确认 m |
| 相对 payload 1 | 待确认 |
| 相对 payload 2 | 待确认 |
| 实际 FOV | 待标定，不只依赖宣传值 |

### 6. 投放机构

分别标记 payload 1 和 payload 2。机构在保持和释放位置都不能碰撞螺旋桨、机臂、相机
或地面，舵机摇臂不能在机械极限处持续堵转。

当前模板值仅用于说明软件现状，不是硬件真值：

| 载荷 | 当前 SERVO 输出 | 当前 release PWM | 当前 hold PWM | 软件偏移 |
| --- | ---: | ---: | ---: | --- |
| payload 1 | 8 | 1750 | 1250 | forward -0.06 m，right 0 m |
| payload 2 | 9 | 1815 | 1185 | forward +0.06 m，right 0 m |

更换舵机、摇臂、机构或飞控后，必须重新空载标定，不能直接照抄这些数值。

### 7. 重心和走线

按比赛状态放置电池、RK3588、相机和两个等重模拟载荷，检查满载、释放第一个载荷和
释放第二个载荷后的重心。动力线与 GPS/罗盘、信号线尽量分离；所有插头做防松、标签
和应力释放，线缆不得进入螺旋桨扫掠区。

## 四、分阶段接线和通电

推荐顺序：

```text
主动力和飞控机械接线
→ DC-DC 空载测量
→ RK3588 单独通电
→ 飞控单独通电
→ MAVLink 链路
→ 下视相机
→ 单个无负载舵机
→ 第二个无负载舵机
→ 完整系统满载运行
```

每一步只新增一类设备，观察电压、电流、温度、异味、异常声音和重启。出现掉压、过热、
反复重启或噪声时立即断电，不要靠软件自动重启掩盖问题。

## 五、无桨台架检查

### 姿态和方向

在地面站或 Web UI 手动小角度抬起机头、右侧和机尾，检查 roll、pitch、yaw 与安装方向
一致。错误应修正机械安装或飞控配置，不能修改比赛坐标代码补偿。

### 相机和 YOLO

软件部署完成后按以下规则验证：

- `pixel_x/ex_norm` 向右为正；
- `pixel_y/ey_norm` 向下为正；
- 没有输入层镜像；
- 移走目标后状态进入 lost/invalid；
- 断开或遮挡相机后不保留旧有效目标。

### 投放机构空载标定

唯一允许的软件链路是：

```text
payload_release → set_servo → MAV_CMD_DO_SET_SERVO
```

这里的 channel 是飞控 **SERVO 输出编号**，不是遥控器 RC 输入通道。禁止 RC override、
旧 `release_payload` 或 Action 直接调用 pymavlink。

| 项目 | payload 1 | payload 2 |
| --- | --- | --- |
| 舵机型号 | 待确认 | 待确认 |
| 允许电压 | 待确认 | 待确认 |
| 堵转电流 | 待确认 | 待确认 |
| 电源/BEC | 待确认 | 待确认 |
| 飞控 SERVO 输出 | 待确认 | 待确认 |
| 保持 PWM 实测 | 待确认 | 待确认 |
| 释放 PWM 实测 | 待确认 | 待确认 |
| 安全机械范围 | 待确认 | 待确认 |
| 模拟载荷测试 | 待确认 | 待确认 |

标定时先让舵机脱开机构或处于不会堵转的位置，一次只连接一路，从安全中位附近逐步确认
方向和范围，再接入无危险模拟载荷。每次动作都检查压降、发热和另一通道是否串扰。

## 组装验收

- [ ] 螺旋桨和正式载荷仍未安装。
- [ ] 飞控、机头、GPS 和相机方向已标记并拍照。
- [ ] RK3588 具备散热、绝缘和线缆应力释放。
- [ ] 满载及两次模拟释放后的重心符合机架要求。
- [ ] 接线总表和供电预算没有未解释的必需项。
- [ ] 所有电源极性、空载电压和负载电压都已实测并由第二人复核。
- [ ] MAVLink 的物理连接、地址或串口参数已明确。
- [ ] 两路 SERVO 输出和 PWM 已完成空载记录。
- [ ] 电源不会因相机、NPU 或舵机动作导致飞控/RK3588 重启。
