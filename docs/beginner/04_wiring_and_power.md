# 04：接线与供电

## 本章目标

建立可审查的接线表和供电预算，先用万用表验证电源，再逐个设备通电。此章不运行飞行
任务、不安装螺旋桨。

预计时间：半天到一天。需要准备：万用表、限流电源或保险方案、说明书、接线标签。

> 错误供电可能立即损坏 RK3588、飞控、相机和舵机。任何电压、极性或引脚不确定时
> 停止操作，查阅具体硬件说明书或询问硬件负责人。

## 先填写两张表

1. [接线总表](../hardware/wiring_table.md)：记录每根线从哪里到哪里；
2. [供电预算](../hardware/power_budget.md)：记录输入电压、峰值电流和 DC-DC 余量。

表格没有填完前不要整体通电。

## 推荐接线顺序

### 1. 主动力和飞控

严格按机架、电调和飞控厂商说明连接。先不连接 RK3588、相机、舵机和桨。

### 2. RK3588 独立稳压供电

确认 DC-DC 输入范围覆盖动力电池满电电压，输出电压符合 RK3588 板卡要求，连续和峰值
电流留有余量。先让 DC-DC 空载上电，用万用表确认输出极性和电压，再连接板卡。

### 3. 飞控与 RK3588 的 MAVLink

当前实机 profile 默认是 Ethernet/UDP-in `0.0.0.0:15001`，但你的实物连接必须根据
飞控和网络模块确认。若改用 UART，需要明确电平、TX/RX 交叉、GND、串口号和波特率。
详见 [MAVLink 连接](../hardware/mavlink_connection.md)。

### 4. 下视相机

确认相机使用 USB、CSI 或网络流，不把视频接口和供电能力混为一谈。USB 相机应考虑
启动峰值、电缆长度和插头防松。

### 5. 投放舵机

舵机供电和 PWM 信号必须符合飞控及舵机说明书。当前模板使用两路飞控 SERVO 输出，
但实际输出编号和 PWM 必须经过空载确认。不要使用 RC override。

## 分阶段通电

每次只新增一类设备：

```text
DC-DC 空载
→ RK3588 单独通电
→ 飞控单独通电
→ MAVLink 链路
→ 下视相机
→ 单个无负载舵机
→ 第二个无负载舵机
→ 完整系统
```

每一步都观察电压、电流、温度、异味、异常声音和重启。如果出现异常，立即断电，不要
继续接入下一设备。

## 共地与隔离

是否共地、哪些电源可以并联、舵机是否需要独立 BEC，必须依据实际硬件电气设计确认。
不能从仓库代码推断。不要把两路稳压输出直接并联，也不要在不了解隔离结构时随意断开
信号参考地。

## 正确结果

- 所有电源输出在连接负载前已测量；
- 完整系统上电后电压稳定，无周期性重启；
- RK3588、飞控和相机能独立断电维护；
- 每根信号线和电源线均能在接线表中找到；
- 两路舵机尚未携带正式载荷。
