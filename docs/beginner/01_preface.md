# 01：前言

这套教程写给第一次接触 RK3588、MAVLink 或自主无人机的同学。它不会让你照抄一架完全
相同的飞机，而是带你从硬件准备、组装、软件环境、仿真到实飞，理解一套比赛无人机是怎样
一步步搭起来的。

## 为什么开源

这不是成熟的方案，有限时间、有限预算下完成。准备过程中发现，真正困难的不只是找到 YOLO、MAVLink 或 ArduPilot 的单独教程，而是如何把它们真正接起来：飞控怎样连接机载计算机，视觉识别怎样进入任务逻辑，目标怎样定位，无人机怎样自主执行任务，又怎样从 SITL 一步步走到实飞。

比赛中允许使用图传，因此我们实际采用手机视频通话辅助观察；飞机上的手机为 RK3588
提供热点，RK3588 再通过 Tailscale 与地面设备通信。在双方能够访问互联网的情况下，
Web UI 不再受普通局域网 Wi-Fi 覆盖距离的直接限制。这只是比赛条件下的一种通信方案，
不代表真正无限距离或可以替代现场飞行安全措施。

项目也有明显不足：侦察部分的 YOLO 识别效果仍然一般，当时数据集数量有限，下视摄像头
画质也比较普通；部分参数和任务逻辑针对 CUADC 比赛；测试、异常处理和代码结构还有很大
改进空间。

希望给其他第一次做自主无人机、第一次参加类似比赛的学生和航模社，提供一个可以参考、复现和继续修改的起点。欢迎通过 Issue 或 Pull Request 一起完善它。

## 项目要完成什么

这套系统最初就是围绕 CUADC 2026 多旋翼无人机侦察与救援任务开发的。

完整任务流程：

```text
比赛场地初始化
  → 起飞
  → 投放区多视角识别与定位
  → 选择两个目标并依次投放
  → 侦察区识别危险标识
  → 生成侦察结果
  → 返回起飞点
  → 视觉辅助降落
```

正式完整模板是 `config/action_missions/rescue_2026_full_auto.json`。当前模板来源于
比赛版本并经过后续整理。不同飞机和场地仍需重新完成 SITL、参数检查和分级实飞验证。

## 系统由什么组成

### 飞控

飞机使用 ArduPilot 飞控，负责姿态稳定、电机输出、GPS、高度等飞行状态和底层飞行
控制。RK3588 不直接驱动电机，而是在飞控之上提供视觉和任务能力。

### RK3588

RK3588 主要运行两个进程：

- `yolo_app`：读取下视相机，使用 RKNNLite 和 RK3588 NPU 完成目标检测与跟踪；
- `app`：接收视觉和飞控状态，运行 Action Mission，提供 Web UI，并向飞控发送高级任务
  请求。

### 相机与通信

下视相机提供视觉输入；RK3588 与 ArduPilot 通过 MAVLink 通信；用户主要通过 Web UI
查看状态和运行任务。

```text
下视相机
    ↓
YOLO / RKNN
    ↓
RK3588
感知 + Action Mission + Web UI
    ↓ MAVLink
ArduPilot
    ↓
无人机
```

## 开始之前

这套教程的目标不是让你照抄一架完全相同的飞机，而是帮助你理解并复现整套系统。

不同机架、飞控、相机、电源和动力系统都可能需要重新配置和测试。涉及真实无人机调试时，
请先完成无桨检查和 SITL 验证。
