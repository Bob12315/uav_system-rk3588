# 硬件图片

本目录统一存放新手教程使用的硬件图片。

- `lowcost-*`：方案 A 的购买记录截图；
- `reference-nanopi-r6c-not-current-bom.png`：NanoPi R6C 的历史参考截图，未列入当前方案 A
  的实际 BOM，不能据此替换 NanoPi T6；
- `stable-*`：方案 B 的升级硬件购买记录截图；后续稳定方案的真实装机照片也放在此目录。

图片文件名应使用小写英文、连字符和明确的硬件名称。新增图片后，请同步更新
[`../../02_hardware_bom.md`](../../02_hardware_bom.md) 中的对应行。
