# 下视相机安装与验证

## 软件当前默认值

根 `config/yolo.yaml` 当前使用 `/dev/video41`、640×480、30 FPS、MJPG。这是当前板端配置，
不是所有相机的通用路径。实机应优先使用稳定的 `/dev/v4l/by-id/...` 或经过验证的 CSI/
网络流配置。

## 图像坐标约定

- 原始检测输入不镜像；
- `pixel_x` 向右为正；
- `pixel_y` 向下为正；
- `ex_norm`：目标在画面右侧为正；
- `ey_norm`：目标在画面下方为正；
- 当前默认 `image_x_sign=1.0`、`image_y_sign=-1.0`。

不要恢复只影响显示或历史调参的镜像修正。发现方向不对时先检查机械安装和实际输入帧。

## 设备检查

```bash
v4l2-ctl --list-devices
ls -l /dev/v4l/by-id/ 2>/dev/null || true
v4l2-ctl --device=<真实设备> --list-formats-ext
```

把经过验证的 source、分辨率、帧率和 FourCC 写入 `config/yolo.yaml`。

## 台架验收

1. 画面中心放置目标；
2. 目标向画面右侧移动，确认 `ex_norm` 为正；
3. 目标向画面下侧移动，确认 `ey_norm` 为正；
4. 移除目标，确认 target 进入 lost/invalid；
5. 遮挡/断开相机，确认系统不保留旧有效目标；
6. 满载运行并检查延迟、丢帧、温度和录像空间。
