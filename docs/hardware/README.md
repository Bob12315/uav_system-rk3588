## 状态标签

建议对每项使用统一状态：

- `待确认`：没有可靠型号或测量；
- `已确认未测试`：型号和接口明确，但没有在本机验证；
- `台架通过`：无桨/空载验证通过；
- `SITL 通过`：只表示软件/任务仿真通过；
- `无载荷实飞通过`：未安装正式载荷；
- `比赛配置验证`：当前完整配置有正式测试记录。

不要把“理论兼容”写成“已验证”。修改硬件后应重新执行相关台架和实飞检查。
