## 分阶段测量

1. DC-DC 不接负载，测极性和输出；
2. 只接 RK3588，记录启动峰值和是否重启；
3. 加入相机和风扇；
4. 加入飞控/MAVLink；
5. 单独驱动一个无机械负载舵机；
6. 两个舵机分别动作；
7. 完整系统运行 YOLO、Web、telemetry 和录像；
8. 在安全条件下记录动力系统工作时的压降和干扰。

任何阶段出现掉压、反复重启、异常温升或噪声，停止并提高供电/布线可靠性，不要靠软件
自动重启掩盖问题。

## 设计检查

- [ ] DC-DC 输入覆盖电池满电电压。
- [ ] 连续和峰值电流均有余量。
- [ ] 舵机堵转不会拉低 RK3588/飞控关键电源。
- [ ] 电源线、连接器和保险能力匹配。
- [ ] 飞控、RK3588 和舵机供电拓扑已画图记录。
- [ ] 整机满载运行至少完成一次稳定性测试。
